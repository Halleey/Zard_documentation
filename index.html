Zard Language

Welcome to Zard Language

The Zard Language is a statically typed, LLVM-backed programming language designed for clarity, performance, and elegance.

Basic Syntax


main {
  int x = 10;
  double y = 3.14;
  print(x + y);
}

LLVM Backend

Zard compiles down to optimized LLVM IR, ensuring native performance and cross-platform portability.

Runtime C Layer

The runtime provides memory-safe structures and utilities implemented in C, used by the generated LLVM IR.
