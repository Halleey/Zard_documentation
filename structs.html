Zard Language

Structs

Structs in Zard are custom composite types that group related fields. They may contain primitives, lists, or other structs recursively. Structs are lightweight value-based constructs and form the foundation of user-defined data modeling.

Declaring a Struct


Struct Pessoa {
    string nome;
    int idade;
}

Nested Structs

Structs can contain other structs:


Struct Endereco {
    string rua;
    string cidade;
    Struct Pais pais;
}

Creating and Assigning Values


Pessoa p;
p.nome = "Alice";
p.idade = 22;

Struct inside Struct


Endereco e;
e.rua = "Rua Central";
e.cidade = "São Paulo";

Pais brasil;
brasil.nome = "Brasil";

e.pais = brasil;

List of Structs


List pessoas;
pessoas.add(p);

Impl: Methods for Structs

The impl block allows attaching functions (methods) directly to a struct, enabling behaviors alongside data.

About s — The Self Reference

Inside an impl block, Zard introduces a special implicit variable named s.

  • s is a reserved keyword of the language.
  • It always refers to the current struct instance the method is operating on.
  • It is equivalent to this in Java, self in Python, or &self / &mut self in Rust.
  • It cannot be reassigned and cannot be shadowed.

Any field access or method call targeting the current struct instance must be accessed through s. 


impl Pessoa {
    function void hello() {
        print("Hello from: ");
        print(s.nome);   # accesses the struct field through 's'
    }
}

Basic Impl Example


Struct Pessoa {
    string nome;
    int idade;
}

impl Pessoa {
    function void hello() {
        print("Olá do método hello()");
    }
}

Pessoa p;
p.nome = "Zard";
p.idade = 22;

p.hello();

Returning the Struct (Method Chaining)

Returning the struct itself allows method chaining. 


impl Pessoa {
    function Pessoa setName(string n) {
        s.nome = n;
        return s;
    }
}

Pessoa p;
p.setName("Lucas")
p.setName("Ana");

Impl with Parametrized Structs


main {

  Struct Item {
    int id;
    string name;
  }

  Struct Set {
    List<Item> data;
  }

  impl Set {

    function addItem(int id, string name) {
      Item it;
      it.id = id;
      it.name = name;
      s.data.add(it);
      return s;
    }

    function removeFirst() {
      if (s.data.size() > 0) {
        s.data.remove(0);
      }
      return s;
    }

    function removeItemById(int id) {
      int i = 0;
      while (i < s.data.size()) {
        Item cur = s.data.get(i);
        if (cur.id == id) {
          s.data.remove(i);
          return s;
        }
        i++;
      }
      return s;
    }

    function prints() {
      int i = 0;
      print("Set {");
      while (i < s.data.size()) {
        Item cur = s.data.get(i);
        print("  Item {");
        print("    id:");
        print(cur.id);
        print("    name:");
        print(cur.name);
        print("  }");
        i++;
      }
      print("}");
      return s;
    }

  }

  Set items;
  items.addItem(1, "Sword");
  items.addItem(2, "Shield");
  items.addItem(3, "Potion");
  items.removeItemById(2);
  items.prints();
}
