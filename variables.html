Zard Language

Variables

In Zard, variables are statically typed — their type must be explicitly declared at compile time. This ensures type safety and consistent behavior across all stages of compilation and execution.

Declaration

The general form for declaring a variable is: 


<type> <name> = <value>;

Examples:


int age = 25;
double pi = 3.1415;
float ratio = 0.75;
string name = "Zard";
boolean active = true;
char letter = 'Z';

Supported Primitive Types

  • int — whole numbers (e.g., 42, -10)
  • double — double-precision floating-point numbers
  • float — single-precision floating-point numbers
  • string — text enclosed in quotes
  • char — single character (e.g., 'A')
  • boolean — logical values: true or false

Uninitialized Variables

You can declare a variable without an initial value, but it must be initialized before use: 


int count;
count = 10;
print(count);

Reassignment

Variables in Zard are mutable — you can freely reassign new values after declaration. 


string word = "hello";
word = "world";
print(word);

Example

The example below declares variables of each primitive type and prints their values: 


main {
  int age = 25;
  double height = 1.82;
  float ratio = 0.75;
  string name = "Zard";
  boolean active = true;
  char initial = 'Z';

  print(age);
  print(height);
  print(ratio);
  print(name);
  print(active);
  print(initial);
}
